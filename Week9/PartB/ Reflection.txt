## ----------Task 1: Dijkstra's Algorithm

1. Explain, in plain English, how does your implementation of Dijkstra's algorithm work?

My code finds the shortest path from Start to End. First, it sets the distance of Start to 0. Other nodes have a very large distance. Then, it uses a PriorityQueue to find the node with the shortest distance. It checks the next nodes and updates their distances. It also saves the previous nodes. At the end, it uses these nodes to show the shortest path.

2. What is the computational complexity of Dijkstra's? Why is it different than BFS / DFS?

My Dijkstra algorithm uses a PriorityQueue. Its time complexity is O((V + E) log V). V is the number of nodes, and E is the number of edges. BFS and DFS have a time complexity of O(V + E). Dijkstra is different because it checks the weights of the edges. BFS and DFS do not use weights to find the shortest path.
